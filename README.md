# Anthony Okolie Portfolio

Personal portfolio website showcasing software engineering projects, technical skills, and professional experience.

## Overview

This portfolio serves as a central hub for my software development work, featuring detailed project pages, architecture diagrams, demonstration videos, and links to source code repositories.

The site highlights projects spanning:

* Full-stack web development
* Backend and microservice architecture
* Real-time systems
* AI-powered applications
* Database design and integration
* Testing and quality assurance

## Featured Projects

### Secure Secret Vault API

A secure secret management API built with Golang, JWT authentication, PostgreSQL, and Docker.

### Real-Time Collaboration Board

A Kanban-style collaboration platform supporting real-time updates using WebSockets, React, Node.js, Redis, PostgreSQL, and Prisma.

### News Intelligence Pipeline

An automated data pipeline that scrapes Hacker News content, analyzes article semantics using OpenAI, and stores insights for trend analysis.

### Studly

A study management platform focused on helping students organize and track learning activities.

### Trade Microservice

An event-driven trade processing service built using Java, Spring Boot, and Kafka.

## Running Locally

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd portfolio
```

Open `index.html` in your browser or run a local development server.
